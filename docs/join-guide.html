How to join our Left 4 Dead 2 server. It takes about 10 minutes the first time, and after that you just connect.

What the host sent you

Type these in and the commands below will fill themselves in. Nothing here leaves your browser.

  1. Get Tailscale on your PC

    Tailscale is a free app that creates a private link between your PC and the server. The server only accepts players who come in through it.

    • Download it from tailscale.com/download and install it.
    • Sign in with Google, Microsoft, GitHub, or Apple. The free plan is all you need.

  2. Accept the invite

    Open the invite link the host sent you and click Accept. This gives you access to the game server only, nothing else on the host's network.

    When it works, the server shows up in your Tailscale app's list of machines.

  3. Get the custom maps

    If the host sent you Steam Workshop links, open each one and click Subscribe, then start Left 4 Dead 2 once so they download. Everyone needs the same maps as the server, or you'll get kicked when it switches to one.

    No links from the host? Skip this step.

  4. Turn on the developer console

    In Left 4 Dead 2, go to Options, then Keyboard/Mouse, and set Allow Developer Console to Enabled. You only do this once.

Stuck?

"Connection failed" or it just times out

This almost always means Tailscale isn't connected. Open the Tailscale app and check that it's switched on and signed in, and that the server appears in your list of machines. If it doesn't appear, open the invite link again and accept it.

Also double-check the address. It should start with 100. and end with :27015.

Pressing ~ doesn't open the console

Check that Allow Developer Console is set to Enabled in step 4. On some keyboard layouts the console key is a different key in the same spot, just below Esc and left of 1.

"Bad password" or I got kicked right away

Type the password command again exactly as the host sent it, then connect. Passwords are case-sensitive.

Kicked for a missing map

You're missing a custom map, or have an older version. Ask the host for the Workshop links, subscribe to each one, restart the game so they download, then connect again.

It lags or rubber-bands

Leave Tailscale connected but close downloads and streams on your network. If it keeps happening, tell the host. Tailscale can show them whether your connection is going direct or through a relay.
